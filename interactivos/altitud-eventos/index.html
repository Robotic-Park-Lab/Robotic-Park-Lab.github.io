Controlar la altitud sólo cuando hace faltaControl altitude only when needed

F. J. Mañas-Álvarez, M. Guinaldo, R. Dormido, R. Socas y S. Dormido · UNED

Un nano-dron vive de su batería. Recalcular el control 100 veces por segundo gasta energía y comunicaciones, y el ruido de los sensores dispara eventos inútiles. Este trabajo propone un umbral de disparo relativo y adaptativo al ruido para el PID de altitud del Crazyflie 2.1: un 93 % menos de actualizaciones con el mismo error.A nano-drone lives on its battery. Recomputing the controller 100 times per second wastes energy and communication, and sensor noise triggers useless events. This work proposes a relative, noise-adaptive triggering threshold for the Crazyflie 2.1 altitude PID: 93% fewer updates with the same error.

¿Cuándo se recalcula el PID?When is the PID recomputed?

El PID de altitud se compara en tres casos. Con eventos, el controlador sólo se ejecuta cuando la altitud medida se aleja lo suficiente del último valor usado, y entre eventos se mantiene la última acción:The altitude PID is compared in three cases. With events, the controller only runs when the measured altitude moves far enough from the last value used; between events the last action is held:

$$t_{k+1}=\inf\{t>t_k:\;|p(t_k)-p(t)| > c_0 + a\,|p(t)-p_{ref}| + c_n(t)\}$$

Caso 3Case 3

Umbral relativoRelative threshold

\(c_0 = 1\) cm, \(a = 0{,}015\) y \(c_n(t)\): máxima desviación de la señal en una ventana de \(l = 20\) muestras, para ignorar el ruido.\(c_0 = 1\) cm, \(a = 0.015\) and \(c_n(t)\): maximum deviation of the signal over a window of \(l = 20\) samples, to ignore noise.

PID discreto con filtro derivativo (periodo variable \(T_k\))Discrete PID with derivative filter (variable period \(T_k\))

$$u_k=K_pe_k+I_k+D_k,\quad I_k=I_{k-1}+K_iT_ke_{k-1},\quad D_k=\frac{K_d}{K_d+N_dT_kK_p}D_{k-1}+\frac{K_dN_d}{K_d/K_p+N_dT_k}(e_k-e_{k-1})$$

Ganancias del artículo: \(K_p = 15000\), \(K_i = 3500\), \(K_d = 9000\) bits/m y \(N_d = 20\); salida PWM de 16 bits sumada al empuje de equilibrio.Gains from the paper: \(K_p = 15000\), \(K_i = 3500\), \(K_d = 9000\) bits/m and \(N_d = 20\); 16-bit PWM output added to the hover thrust.
