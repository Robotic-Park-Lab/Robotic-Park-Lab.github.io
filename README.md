# Documentación de ramas y guía de contribución — Robotic-Park-Lab.github.io

Esta rama (`doc`) no contiene código: solo explica para qué sirve cada rama del repositorio y cómo contribuir. Es el sitio web del laboratorio, servido por GitHub Pages en https://robotic-park-lab.github.io/.

## Ramas de este repositorio

| Rama | Propósito |
|---|---|
| `main` | Única rama de contenido. GitHub Pages sirve directamente desde aquí — cualquier push a `main` se publica en cuestión de minutos. |
| `doc` (esta) | Documentación de ramas y guía de contribución, común a todo el laboratorio. |

## Guía de contribución

- HTML/CSS plano, sin build step. Antes de un PR, abre el fichero modificado en un navegador para comprobar que se ve bien.
- Las tarjetas de la página `plataforma.html` deben apuntar al nombre y descripción reales de cada repositorio del laboratorio — si renombras o retiras un repo, actualiza también esta página.
